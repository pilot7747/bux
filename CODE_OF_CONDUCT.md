# Code of conduct

bux follows the
[Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/),
in its issues, pull requests and discussions, and anywhere else you speak for the
project. In short: be welcoming and kind, assume good faith, credit others' work, and
leave no room for harassment.

## Reporting

Report a breach of the code to the maintainer, Nikita Pavlichenko, at
[nikita.v.pavlichenko@gmail.com](mailto:nikita.v.pavlichenko@gmail.com). Reports are
kept confidential. The maintainer addresses them as the Covenant's "Addressing and
Repairing Harm" section describes, from a warning up to a permanent ban.
